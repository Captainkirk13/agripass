The scanner camera does not start

  • Browsers only allow the camera on secure (HTTPS) addresses. On phones, open the scanner using the HTTPS address your administrator gave you, not one starting with http://.
  • If the browser asked for camera permission and it was blocked, allow it in the browser's site settings, then reload.
  • Close other apps that may be using the camera (video calls, the camera app).
  • Recommended browsers: Chrome on Android, Safari on iPhone and iPad.

"No active event"

No event is set as the active event, or it was marked completed. On the scanner, pick an event from the list. Admins can set the active event from the dashboard.

The scanner says Offline although there is signal

The scanner checks the server regularly and switches back on its own. To force it, reload the page; scans waiting to upload are kept. If it stays offline, the server or venue network may be blocking it: keep scanning offline and let it sync later.

An attendee cannot check in

Verify the attendee is registered for this event and that the scanner is set to the correct session. Refresh the roster on offline scanners, then scan again.

The scanner says location is required, or "Outside the venue"

  • Open the scanner on the https address. Browsers do not share location on a plain http page, except on this computer's localhost.
  • Allow location for the site, and turn on the phone's location services. Indoors, stand near a window if the first reading times out.
  • If the whole room is rejected, an admin should widen the check-in radius on the event. Phone location is often 50–100 m off indoors, so a radius of about 200 m is a practical start.

Someone was checked in to the wrong session

Attendance cannot be edited from the scanner. Note the name and time and tell an admin. This matters for certificate eligibility.

Emails are not arriving

  • Ask the attendee to check spam and confirm the address they used.
  • Correct a mistyped address on the Members page, then resend.
  • If no emails arrive for anyone, the mail server settings need checking: contact the system administrator.

Getting help

For problems not covered here, note what you were doing, the exact message on screen and the time, and contact your AgriPass system administrator.
